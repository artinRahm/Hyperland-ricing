Layout Examples

Common window management layouts and workflows.

Grid (2x2)

Four equal windows. Great for monitoring multiple terminals or code + preview.

$mainMod + g

Main + Stack

Main window takes 60-70%, others stack on side. Ideal for coding workflow.

$mainMod + m

Split Vertical

Two windows side by side. Perfect for editor + terminal or diff views.

$mainMod + v

Split Horizontal

Two windows stacked. Good for reading docs on top, coding below.

$mainMod + h

Floating

Free-floating windows for dialogs, calculators, media players.

$mainMod + Shift + Space

Tabbed

Windows grouped in tabs. Switch with $mainMod + Tab.

$mainMod + t
