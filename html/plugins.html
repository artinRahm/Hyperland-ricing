Essential Plugins & Tools

Complete your Hyprland setup with bars, launchers, lockscreens, and utilities

Waybar

The most popular status bar for Wayland compositors. Highly customizable with CSS.

Installation

Arch Linux
sudo pacman -S waybar
NixOS
waybar = {
  enable = true;
  package = pkgs.waybar;
  settings = {
    // config here
  };
};

Hyprlock

Hyprland's native lockscreen. GPU-accelerated, highly customizable.

Install
# Arch
sudo pacman -S hyprlock

# NixOS
hyprlock = {
  enable = true;
  package = pkgs.hyprlock;
};

Configuration

hyprlock.conf
background {
    monitor =
    path = ~/Pictures/wallpapers/lockscreen.jpg
    color = #1e1e2e
    size = cover
    blur_passes = 3
    blur_size = 8
    noise = 0.0117
    contrast = 1.0
    brightness = 0.8
    vibrancy = 0.169
    vibrancy_darkness = 0.0
}

input-field {
    monitor =
    size = 300, 50
    outline_thickness = 2
    dots_size = 0.3
    dots_spacing = 0.5
    dots_center = true
    dots_rounding = -1
    outer_color = #f5c2e7
    inner_color = #89dceb
    font_color = #cdd6f4
    font_size = 24
    font_family = JetBrains Mono
    placeholder_text = 
    placeholder_font_color = #6c7086
    hide_input = true
    swap_font_color = #1e1e2e
    swap_inner_color = #f5c2e7
    check_keymap = true
    keymap_text = {layout}
    keymap_font_color = #cdd6f4
    keymap_font_size = 14
    keymap_font_family = JetBrains Mono
    rounding = 12
    inactive_inner_color = #313244
    inactive_outer_color = #45475a
    inactive_font_color = #6c7086
}

label {
    monitor =
    text = Hi, $USER
    color = #cdd6f4
    font_size = 32
    font_family = JetBrains Mono
    position = 0, -100
    halign = center
    valign = center
}

label {
    monitor =
    text = $(date +%H:%M)
    color = #89dceb
    font_size = 64
    font_family = JetBrains Mono
    position = 0, -30
    halign = center
    valign = center
}

label {
    monitor =
    text = $(date +%A, %B %d)
    color = #6c7086
    font_size = 18
    font_family = JetBrains Mono
    position = 0, 40
    halign = center
    valign = center
}

Hypridle

Idle daemon for Hyprland - handles sleep, lock, dpms.

hypridle.conf
general {
    lock_cmd = hyprlock
    before_sleep_cmd = loginctl lock-session
    after_sleep_cmd = hyprctl dispatch dpms on
}

listener {
    timeout = 300
    on_timeout = hyprlock
    on_resume = hyprctl dispatch dpms on
}

listener {
    timeout = 600
    on_timeout = hyprctl dispatch dpms off
    on_resume = hyprctl dispatch dpms on
}

listener {
    timeout = 1800
    on_timeout = systemctl suspend
    on_resume = hyprctl dispatch dpms on
}

Hyprpicker

Color picker for Hyprland. Pick colors from anywhere on screen.

Install
# Arch
sudo pacman -S hyprpicker

# Usage
hyprpicker -a  # copies to clipboard
hyprpicker -r  # rgb format
hyprpicker -f hex  # hex format

Keybinding

hyprland.conf
bind = $mainMod SHIFT, C, exec, hyprpicker -a

Hyprcursor

Cursor manager for Hyprland with theme support.

Config
env = HYPRCURSOR_THEME,Bibata-Modern-Classic
env = HYPRCURSOR_SIZE,24

# Or in hyprland.conf
cursor {
    theme = Bibata-Modern-Classic
    size = 24
    no_hardware_cursors = false
}

Hyprpaper

Wallpaper utility for Hyprland with multi-monitor support.

hyprpaper.conf
preload = ~/Pictures/wallpapers/wall1.jpg
preload = ~/Pictures/wallpapers/wall2.png

wallpaper = eDP-1,~/Pictures/wallpapers/wall1.jpg
wallpaper = HDMI-A-1,~/Pictures/wallpapers/wall2.png

# Random wallpaper on startup
# wallpaper = ,~/Pictures/wallpapers/

ipc = on
splash = false

Other Essential Utilities

Screen brightness control.

sudo pacman -S brightnessctl

Bluetooth

sudo pacman -S blueman

sudo pacman -S networkmanager

Audio

sudo pacman -S pipewire wireplumber pavucontrol

GTK Theming

nwg-look or gnome-themes-extra.

sudo pacman -S nwg-look
