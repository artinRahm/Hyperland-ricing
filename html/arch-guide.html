Arch Linux

Arch Linux Installation Guide

Complete step-by-step guide to installing and configuring Hyprland on Arch Linux

Prerequisites

Before installing Hyprland, ensure you have a working Arch Linux base system. If you haven't installed Arch yet, follow the official installation guide.

Note: This guide assumes you have a working Arch Linux installation with a user account that has sudo privileges.

System Requirements

  • Arch Linux (up to date: sudo pacman -Syu)
  • Kernel 6.1+ (for best Wayland support)
  • GPU with Mesa/Vulkan support (Intel, AMD, or NVIDIA)
  • At least 2GB RAM (4GB+ recommended)

Installing Hyprland

Option 1: Stable Release (Recommended)

Install Hyprland from the official Arch repositories:

sudo pacman -S hyprland

Option 2: Git Version (Latest Features)

For the latest features and fixes, install from AUR:

# Using yay
yay -S hyprland-git

# Or using paru
paru -S hyprland-git
Warning: The git version may have breaking changes. Read the release notes before updating.

GPU Drivers

Proper GPU drivers are essential for Wayland/Hyprland to work correctly.

AMD (Radeon)

AMD has the best out-of-the-box Wayland support.

sudo pacman -S mesa lib32-mesa vulkan-radeon lib32-vulkan-radeon

For newer GPUs, also install:

sudo pacman -S amdgpu-top

Intel (Integrated / Arc)

sudo pacman -S mesa lib32-mesa vulkan-intel lib32-vulkan-intel intel-media-driver

For Intel Arc GPUs, ensure kernel 6.2+ and add i915.force_probe=* to kernel parameters if needed.

NVIDIA (Proprietary)

NVIDIA requires additional configuration for Wayland.

# Install drivers
sudo pacman -S nvidia nvidia-utils lib32-nvidia-utils nvidia-settings

# For DKMS (if using custom kernels)
sudo pacman -S nvidia-dkms nvidia-utils lib32-nvidia-utils nvidia-settings

Required Kernel Parameters

Add to your bootloader (GRUB/systemd-boot):

nvidia_drm.modeset=1 nvidia_drm.fbdev=1

Environment Variables

Add to ~/.config/hypr/hyprland.conf or /etc/environment:

env = LIBVA_DRIVER_NAME,nvidia
env = __GLX_VENDOR_LIBRARY_NAME,nvidia
env = WLR_NO_HARDWARE_CURSORS,1
env = GBM_BACKEND,nvidia-drm
env = __GL_GSYNC_ALLOWED,0
env = __GL_VRR_ALLOWED,0

Virtual Machines

# For QEMU/KVM with virtio-gpu
sudo pacman -S mesa qemu-guest-agent

# For VirtualBox
sudo pacman -S virtualbox-guest-utils mesa
sudo systemctl enable vboxservice

Enable 3D acceleration in VM settings. Wayland works best with virtio-gpu (QEMU) or VMSVGA (VirtualBox).

Basic Configuration

Hyprland configuration file is located at ~/.config/hypr/hyprland.conf. Copy the example config first:

mkdir -p ~/.config/hypr
cp /usr/share/hyprland/hyprland.conf ~/.config/hypr/hyprland.conf

Essential Configuration Sections

Monitor Configuration

monitor=,preferred,auto,1
# For multiple monitors:
# monitor=eDP-1,1920x1080@60,0x0,1
# monitor=HDMI-A-1,2560x1440@144,1920x0,1

Input Configuration

input {
    kb_layout = us
    kb_variant =
    kb_model =
    kb_options =
    kb_rules =

    follow_mouse = 1
    touchpad {
        natural_scroll = true
        tap-to-click = true
        tap-and-drag = true
    }
}

Appearance (Gaps, Borders, Blur)

general {
    gaps_in = 5
    gaps_out = 10
    border_size = 2
    col.active_border = rgba(ff6ec7ee) rgba(8b5cffee) 45deg
    col.inactive_border = rgba(1a1a2eee)
    layout = dwindle
    allow_tearing = false
}

decoration {
    rounding = 10
    blur {
        enabled = true
        size = 8
        passes = 3
        new_optimizations = true
    }
    drop_shadow = true
    shadow_range = 4
    shadow_render_power = 3
    col.shadow = rgba(1a1a2eaa)
}

Animations

animations {
    enabled = true
    bezier = myBezier, 0.05, 0.9, 0.1, 1.05
    bezier = linear, 0, 0, 1, 1

Autostart Applications

Add to your hyprland.conf:

exec-once = waybar &
exec-once = swaybg -i ~/.config/hypr/wallpaper.jpg &
exec-once = swaync &
exec-once = nm-applet --indicator &
exec-once = blueman-applet &
exec-once = /usr/lib/polkit-gnome/polkit-gnome-authentication-agent-1 &

# For clipboard history
exec-once = cliphist store &

# For idle management
exec-once = swayidle -w \
    timeout 300 'swaylock -f -c 1a1a2e' \
    timeout 600 'hyprctl dispatch dpms off' \
    resume 'hyprctl dispatch dpms on' &

Common Issues

Hyprland won't start / Black screen

  • Check GPU drivers are installed correctly
  • Ensure you're not running as root
  • Check hyprland command output for errors
  • Try Hyprland (capital H) from TTY

No wallpaper / Black background

# Install swaybg
sudo pacman -S swaybg

# Set wallpaper
swaybg -i /path/to/wallpaper.jpg -m fill

Audio not working

# Ensure PipeWire is running
systemctl --user enable --now pipewire wireplumber pipewire-pulse

# Check status
wpctl status

Screen tearing

Add to hyprland.conf:

general {
    allow_tearing = false
}

For NVIDIA, ensure nvidia_drm.modeset=1 is in kernel parameters.

External monitor not detected

# Check available monitors
hyprctl monitors

# Manually configure
monitor=HDMI-A-1,preferred,auto,1
