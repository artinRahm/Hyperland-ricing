Troubleshooting

Troubleshooting Guide

Solutions for common Hyprland issues and how to debug problems

Getting Help

Before troubleshooting, gather information:

Debug info commands
# Hyprland version and config
hyprctl version
hyprctl monitors
hyprctl clients
hyprctl workspaces
hyprctl devices

# Check logs
journalctl -u hyprland -f
# Or if started manually
hyprland -d 2>&1 | tee hyprland.log

# System info
inxi -G
glxinfo | grep -i opengl
vulkaninfo | grep -i device

Official Resources

  • Hyprland Wiki
  • GitHub Issues

When Reporting Bugs

  • Hyprland version (hyprctl version)
  • GPU + driver version
  • Minimal config that reproduces issue
  • Steps to reproduce
  • Logs from hyprland -d

Startup Issues

Hyprland Won't Start

Black screen / crashes immediately

Solutions:

  1. Check you're on a TTY, not inside another DE
  2. Ensure GPU drivers installed: sudo pacman -S mesa vulkan-radeon (AMD) or nvidia (NVIDIA)
  3. Try: Hyprland from TTY (not via display manager)
  4. Check hyprctl version works
  5. Disable config: mv ~/.config/hypr/hyprland.conf ~/.config/hypr/hyprland.conf.bak

"Failed to create EGL context"

Fix:

# AMD/Intel
sudo pacman -S mesa libva-mesa-driver mesa-vdpau

# NVIDIA
sudo pacman -S nvidia nvidia-utils libva-nvidia-driver

# Ensure user in video group
sudo usermod -aG video $USER

Config Syntax Errors

Validate config:

hyprctl reload  # Shows errors if any
# Or test without applying
hyprctl -j getoption general:layout

GPU Driver Issues

NVIDIA Specific

Required kernel parameters
# /etc/default/grub
GRUB_CMDLINE_LINUX_DEFAULT="... nvidia_drm.modeset=1 nvidia_drm.fbdev=1"

# Then: sudo grub-mkconfig -o /boot/grub/grub.cfg
Hyprland NVIDIA env vars
env = LIBVA_DRIVER_NAME,nvidia
env = __GLX_VENDOR_LIBRARY_NAME,nvidia
env = NVD_BACKEND,direct
env = WLR_NO_HARDWARE_CURSORS,1
env = WLR_DRM_NO_ATOMIC,1

# For older cards (Kepler/Maxwell)
# env = WLR_RENDERER_ALLOW_SOFTWARE,1

AMD/Intel

Ensure packages installed
# AMD
sudo pacman -S mesa vulkan-radeon libva-mesa-driver mesa-vdpau

# Intel
sudo pacman -S mesa vulkan-intel libva-intel-driver intel-media-driver

# Check
glxinfo -B
vulkaninfo --summary

Hybrid Graphics (Optimus)

Setup
# Install
sudo pacman -S nvidia-prime optimus-manager

# Or use envycontrol (AUR)
# envycontrol -s hybrid

# Hyprland config
env = WLR_DRM_DEVICES,/dev/dri/card0:/dev/dri/card1
env = __GLX_VENDOR_LIBRARY_NAME,nvidia
env = WLR_NO_HARDWARE_CURSORS,1

Performance Issues

Low FPS / Stuttering

Checklist:

  • Disable animations: animations { enabled = no }
  • Disable blur: decoration { blur { enabled = no } }
  • Check VRR: hyprctl monitors - look for VRR: 1
  • Disable tear prevention: general { allow_tearing = true }
  • Use hyprctl setprop debug:damage_tracking 1 to visualize redraws

High CPU Usage

Common causes:

  • Too many Waybar modules polling frequently
  • Animated wallpapers (hyprpaper with slideshow)
  • Shader-heavy Waybar CSS
  • Background processes polling hyprctl

Profile with: perf top -p $(pidof Hyprland)

Memory Leaks

Workarounds:

  • Restart Hyprland periodically: bind = $mainMod SHIFT, R, reload
  • Check for memory leaks in Waybar widgets
  • Update to latest Hyprland version

Wayland Application Issues

Apps Not Using Wayland

Force Wayland
# Firefox
# about:config -> widget.wayland-dmabuf-vaapi.enabled = true
# MOZ_ENABLE_WAYLAND=1 firefox

# Chrome/Electron
# --enable-features=WaylandWindowDecorations --ozone-platform=wayland

# Qt apps
env = QT_QPA_PLATFORM,wayland
env = QT_WAYLAND_DISABLE_WINDOWDECORATION,1

# Java
# _JAVA_AWT_WM_NONREPARENTING=1

XWayland Issues

Fixes:

  • Install xorg-xwayland
  • For games: general { xwayland { force_zero_scaling = true } }
  • DPI issues: env = GDK_SCALE,1 env = GDK_DPI_SCALE,1

Screen Sharing / Recording

Required portals
# Arch
sudo pacman -S xdg-desktop-portal-hyprland xdg-desktop-portal-gtk

# NixOS
xdg-desktop-portal-hyprland = {
  enable = true;
};

# For browsers, restart after install
# Check: xdg-desktop-portal --version

Audio Issues

No Sound / PipeWire

Install & Enable
sudo pacman -S pipewire wireplumber pipewire-pulse pipewire-alsa pipewire-jack
systemctl --user enable --now pipewire wireplumber

# Check status
wpctl status
pactl info

Bluetooth Audio

Setup
sudo pacman -S bluez bluez-utils blueman
sudo systemctl enable --now bluetooth
# Add user to bluetooth group if needed
sudo usermod -aG bluetooth $USER

Input & Keyboard Issues

Keyboard Layout Not Working

Hyprland config
input {
    kb_layout = us,de
    kb_variant = ,nodeadkeys
    kb_options = grp:alt_shift_toggle,caps:escape
    kb_model = pc105
    kb_repeat_rate = 25
    kb_repeat_delay = 250
}

Caps Lock as Escape

Options
# In input section
kb_options = caps:escape          # Caps = Escape
kb_options = caps:swapescape      # Swap Caps & Escape
kb_options = ctrl:nocaps          # Caps = Ctrl

Mouse/Touchpad Not Working

Libinput config
input {
    sensitivity = 0
    accel_profile = flat
    tap-to-click = true
    natural_scroll = true
    scroll_factor = 1
    scroll_method = two_finger
}

Multi-Monitor Issues

Monitor Not Detected

Debug:

# List all outputs
hyprctl monitors -j
ls /sys/class/drm/

# Force enable
monitor=HDMI-A-1,preferred,auto,1

# Check kernel
dmesg | grep -i drm

Wrong Resolution/Refresh Rate

Explicit config
monitor=HDMI-A-1,2560x1440@144,0x0,1
monitor=eDP-1,1920x1080@60,2560x0,1

# Get available modes
cat /sys/class/drm/card0-HDMI-A-1/modes

Different DPI Per Monitor

Scaling
monitor=eDP-1,preferred,auto,1.5
monitor=DP-1,3840x2160@60,0x0,2

# For XWayland apps
env = GDK_SCALE,2
env = GDK_DPI_SCALE,0.5

NixOS Specific Issues

Hyprland Not in Session List

configuration.nix
services.xserver.displayManager.greetd = {
  enable = true;
  defaultSession = {
    command = "Hyprland";
    user = "youruser";
  };
};

# Or for SDDM
services.xserver.displayManager.sddm = {
  enable = true;
  wayland = true;
};

Home Manager Not Applying

Flake setup
# flake.nix
homeConfigurations."user@host" = homeManagerConfiguration {
  pkgs = pkgs;
  modules = [ ./home.nix ];
};

# Rebuild
sudo nixos-rebuild switch --flake .#hostname
home-manager switch --flake .#user@host

Missing Fonts in Waybar/Rofi

Add to home.nix
fonts.packages = with pkgs; [
  jetbrains-mono
  noto-fonts
  noto-fonts-emoji
  font-awesome
];

# Or system-wide
fonts.fonts = with pkgs; [ jetbrains-mono noto-fonts-emoji ];

Hyprland Plugins Not Loading

Hyprland plugins
# flake.nix
hyprland = {
  enable = true;
  package = pkgs.hyprland.withPlugins (p: with p; [
    hyprland-dynamic-cursors
    hyprland-autoname-workspaces
  ]);
};

Quick Reference Card

Essential Commands

hyprctl reload              # Reload config
hyprctl monitors           # List monitors
hyprctl clients            # List windows
hyprctl workspaces         # List workspaces
hyprctl devices            # Input devices
hyprctl version            # Version info
hyprctl dispatch ...       # Send commands
hyprctl keyword ...        # Set options live
hyprctl getoption ...      # Get current value

Useful Keybindings

$mainMod + Q        # Close window
$mainMod + Return   # Terminal
$mainMod + D        # App launcher
$mainMod + Shift+R  # Reload config
$mainMod + F        # Fullscreen
$mainMod + Shift+F  # Fake fullscreen
$mainMod + Shift+Space # Toggle float
$mainMod + Mouse    # Move window
$mainMod+Shift+Mouse # Resize window

Log Locations

# Systemd
journalctl -u hyprland -f
journalctl --user -u hyprland -f

# Manual start

$XDG_STATE_HOME/hypr/
$XDG_RUNTIME_DIR/hypr/
