Configuration

Hyprland Configuration

Master your hyprland.conf - keybindings, window rules, animations, and advanced settings

Config Structure

Hyprland uses a single configuration file at ~/.config/hypr/hyprland.conf. The config is organized into sections:

hyprland.conf
# Monitor configuration
monitor=eDP-1,preferred,auto,1
monitor=HDMI-A-1,1920x1080@60,1920x0,1

# Input settings
input {
    kb_layout = us
    kb_variant =
    kb_model =
    kb_options = caps:escape
    kb_repeat_rate = 25
    kb_repeat_delay = 600
    sensitivity = 0
    accel_profile = flat
}

# General settings
general {
    gaps_in = 5
    gaps_out = 10
    border_size = 2
    col.active_border = rgba(89b4faee) rgba(89b4faee) 45deg
    col.inactive_border = rgba(313244ee)
    layout = dwindle
    allow_tearing = false
}

# Decoration
decoration {
    rounding = 10
    blur {
        enabled = true
        size = 8
        passes = 3
        new_optimizations = true
    }
    drop_shadow = true
    shadow_range = 4
    shadow_render_power = 3
    col.shadow = rgba(1a1a2eaa)
}

# Animations
animations {
    enabled = yes
    bezier = myBezier, 0.05, 0.9, 0.1, 1.05
    animation = windows, 1, 7, myBezier
    animation = windowsOut, 1, 7, default, popin 80%
    animation = border, 1, 10, default
    animation = borderangle, 1, 8, default
    animation = fade, 1, 7, default
    animation = workspaces, 1, 6, default
}

# Keybindings (see Keybindings section)
$mainMod = SUPER

bind = $mainMod, Q, killactive,
bind = $mainMod, Return, exec, kitty
bind = $mainMod, D, exec, rofi -show drun

# Window rules (see Window Rules section)
windowrulev2 = float, class:^(pavucontrol)$
windowrulev2 = size 800 600, class:^(pavucontrol)$
windowrulev2 = center, class:^(pavucontrol)$

Essential Keybindings

Define your workflow with custom keybindings. $mainMod is typically SUPER (Windows key).

Window Management

Window keybindings
# Close window
bind = $mainMod, Q, killactive,

# Move focus
bind = $mainMod, left, movefocus, l
bind = $mainMod, right, movefocus, r
bind = $mainMod, up, movefocus, u
bind = $mainMod, down, movefocus, d

# Swap windows
bind = $mainMod SHIFT, left, swapwindow, l
bind = $mainMod SHIFT, right, swapwindow, r
bind = $mainMod SHIFT, up, swapwindow, u
bind = $mainMod SHIFT, down, swapwindow, d

# Fullscreen
bind = $mainMod, F, fullscreen, 1
bind = $mainMod SHIFT, F, fullscreen, 0

# Toggle floating
bind = $mainMod SHIFT, space, togglefloating,

# Move/resize floating
bind = $mainMod, mouse_down, moveresize, move
bind = $mainMod SHIFT, mouse_down, moveresize, resize

Workspaces

Workspace keybindings
# Switch workspace
bind = $mainMod, 1, workspace, 1
bind = $mainMod, 2, workspace, 2
bind = $mainMod, 3, workspace, 3
bind = $mainMod, 4, workspace, 4
bind = $mainMod, 5, workspace, 5

# Move window to workspace
bind = $mainMod SHIFT, 1, movetoworkspace, 1
bind = $mainMod SHIFT, 2, movetoworkspace, 2
bind = $mainMod SHIFT, 3, movetoworkspace, 3
bind = $mainMod SHIFT, 4, movetoworkspace, 4
bind = $mainMod SHIFT, 5, movetoworkspace, 5

# Workspace navigation
bind = $mainMod, Tab, workspace, e+1
bind = $mainMod SHIFT, Tab, workspace, e-1

# Special workspace (scratchpad)
bind = $mainMod, S, togglespecialworkspace, magic
bind = $mainMod SHIFT, S, movetoworkspace, special:magic

Applications

App launchers
$terminal = kitty
$menu = rofi -show drun
$browser = firefox
$files = thunar

bind = $mainMod, Return, exec, $terminal
bind = $mainMod, D, exec, $menu
bind = $mainMod SHIFT, D, exec, $browser
bind = $mainMod, E, exec, $files

# Screenshot
bind = , Print, exec, grim -g "$(slurp)" - | wl-copy
bind = SHIFT, Print, exec, grim - | wl-copy

# Audio
bind = , XF86AudioRaiseVolume, exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
bind = , XF86AudioLowerVolume, exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bind = , XF86AudioMute, exec, wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle

Window Rules

Window rules (v2 syntax) let you control window behavior automatically.

Window rules examples
# Float specific apps
windowrulev2 = float, class:^(pavucontrol|nm-connection-editor|blueman-manager)$
windowrulev2 = float, title:^(Picture-in-Picture)$

# Size and position for floating windows
windowrulev2 = size 800 600, class:^(pavucontrol)$
windowrulev2 = center, class:^(pavucontrol)$

# Make specific apps fullscreen
windowrulev2 = fullscreen, class:^(firefox|chrome)$ title:^(.* - YouTube)$

# Assign apps to workspaces
windowrulev2 = workspace 2, class:^(firefox|chrome|brave)$
windowrulev2 = workspace 3, class:^(code|code-oss)$
windowrulev2 = workspace 4, class:^(discord|slack|telegram)$
windowrulev2 = workspace 5, class:^(spotify|mpv)$

# Opacity rules
windowrulev2 = opacity 0.95 0.95, class:^(kitty|alacritty)$
windowrulev2 = opacity 0.9 0.9, class:^(rofi|wofi)$

# Disable rounding for specific apps
windowrulev2 = rounding 0, class:^(firefox|chrome)$

# No animations for specific apps
windowrulev2 = animation none, class:^(mpv|vlc)$

# Pin to all workspaces
windowrulev2 = pin, class:^(polybar|waybar)$

Animations

Customize animations with bezier curves for smooth transitions.

Animation config
animations {
    enabled = yes

    # Custom bezier curves
    bezier = smooth, 0.25, 0.46, 0.45, 0.94
    bezier = snappy, 0.05, 0.9, 0.1, 1.05
    bezier = bounce, 0.68, -0.55, 0.27, 1.55
    bezier = linear, 0, 0, 1, 1

    # Window animations
    animation = windows, 1, 7, smooth
    animation = windowsOut, 1, 5, smooth, popin 80%
    animation = border, 1, 10, linear
    animation = borderangle, 1, 8, linear
    animation = fade, 1, 7, smooth
    animation = workspaces, 1, 6, smooth

    # Special workspace animation
    animation = specialWorkspace, 1, 10, bounce

    # Disable all animations (for performance)
    # enabled = no
}
Tip: Use hyprctl animation to test animations live. Disable with enabled = no for maximum performance.

Gaps & Borders

Fine-tune spacing and window borders for your perfect setup.

Gaps & borders
general {
    # Inner gaps (between windows)
    gaps_in = 5

    # Outer gaps (window to screen edge)
    gaps_out = 10

    # Workspace-specific gaps
    # workspace = 1, gaps_in:10, gaps_out:20

    # Border size
    border_size = 2

    # Active window border (gradient)
    col.active_border = rgba(89b4faee) rgba(f5c2e7ee) 45deg

    # Inactive window border
    col.inactive_border = rgba(313244ee)

    # Grouped window border (tabbed/tiled groups)
    col.group_border = rgba(89b4faee) rgba(f5c2e7ee) 45deg

    # Urgent window border (notifications)
    col.urgent_border = rgba(f38ba8ee)

    # Resize border
    resize_on_border = true
    extend_border_grab_area = 15
}

Monitor Configuration

Configure single or multi-monitor setups with proper scaling and positioning.

Monitor config
# Single monitor
monitor=eDP-1,preferred,auto,1

# Dual monitor (laptop + external)
monitor=eDP-1,1920x1080@60,0x0,1
monitor=HDMI-A-1,2560x1440@144,1920x0,1

# High DPI scaling
monitor=eDP-1,preferred,auto,1.5
monitor=DP-1,3840x2160@60,0x0,2

# Mirror mode
monitor=eDP-1,preferred,auto,1,mirror,HDMI-A-1

# Disable monitor
# monitor=HDMI-A-1,disable

# Variable refresh rate (VRR)
monitor=eDP-1,preferred,auto,1,vrr,1

# Transform (rotation)
# monitor=DP-1,preferred,auto,1,transform,1  # 90°
# monitor=DP-1,preferred,auto,1,transform,2  # 180°

Input Settings

Configure keyboard, mouse, and touchpad behavior.

Input config
input {
    # Keyboard
    kb_layout = us
    kb_variant = dvorak
    kb_model =
    kb_options = caps:escape,grp:alt_shift_toggle
    kb_repeat_rate = 30
    kb_repeat_delay = 250
    kb_numlock = true

    # Mouse
    sensitivity = 0
    accel_profile = flat
    scroll_factor = 1
    scroll_points = false
    scroll_method = two_finger
    tap-to-click = true
    tap-and-drag = true
    drag_lock = false
    disable_while_typing = true
    left_handed = false
    natural_scroll = false

    # Touchpad gestures
    gesture_workspace_swipe = true
    gesture_workspace_swipe_fingers = 3
    gesture_workspace_swipe_distance = 300
    gesture_workspace_swipe_invert = false

    # Touchpad
    touchpad {
        natural_scroll = true
        tap-to-click = true
        tap-and-drag = true
        drag_lock = false
        disable_while_typing = true
    }

    # Tablet
    tablet {
        mapped_to_output = eDP-1
    }
}

Miscellaneous

Misc settings
general {
    # Layout algorithm: dwindle | master
    layout = dwindle

    # Master layout settings
    master_width_factor = 0.55

    # Allow screen tearing (for games)
    allow_tearing = false

    # Focus follows mouse
    focus_on_open = true
    no_focus_fallback = false

    # Cursor
    cursor_inactive_timeout = 300
    cursor_zoom_factor = 1.0
    cursor_zoom_rigidity = 10

    # Snap windows
    snap {
        enabled = true
        distance = 20
    }

    # XWayland
    xwayland {
        force_zero_scaling = true
    }

    # Misc
    inactive_alpha = 0.9
    border_no_pixel = false
}

Debug commands

bind = $mainMod SHIFT, R, reload

# Get current config
# hyprctl getoption general:gaps_in

# List all options
# hyprctl options
